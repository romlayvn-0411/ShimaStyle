# ShimaReborn

ShimaReborn (phiên bản làm lại hoàn toàn của ShimaStyle) là một Tweak tinh chỉnh thông báo tối thượng dành cho các thiết bị Jailbreak. Nó ép toàn bộ thông báo hệ thống chuyển hóa thành dạng viên thuốc Dynamic Island tuyệt đẹp với hiệu năng Native (chuẩn gốc) 100%.

## ✨ Tính Năng Nổi Bật (Ultimate Features)

- 🚀 **Native View Morphing:** Hoạt động hoàn toàn dựa trên khung UI gốc của Apple. Không có độ trễ (0ms delay), giữ nguyên 100% các cử chỉ nguyên bản (Vuốt lên để xóa, Vuốt xuống xem chi tiết, Chạm để mở).
- 🌟 **Aura Glow:** Viền sáng ma thuật tự động phân tích và đổi màu theo màu sắc chủ đạo của Icon ứng dụng (Ví dụ: Zalo viền xanh, YouTube viền đỏ).
- 📳 **Haptic Feedback:** Tích hợp phản hồi xúc giác (Rung Rigid) sang trọng mỗi khi thông báo nảy ra trên màn hình.
- 🎨 **Tùy Biến Nền Cao Cấp:** Hỗ trợ đổi hình nền thông báo bằng Ảnh tĩnh, Ảnh động (GIF), Video (MP4) hoặc Kính mờ (Blur) thích ứng Sáng/Tối.
- ⚙️ **Siêu Cấu Hình:** Tùy chỉnh tự do kích thước, độ trễ, thời gian hiển thị, căn chỉnh tọa độ (X/Y) khi ở chế độ dọc/ngang (chơi game).

## 📱 Tương Thích

- **Hệ điều hành:** Hỗ trợ iOS 16.0 đến iOS 18.x
- **Kiến trúc:** Rootless (Dopamine, Roothide, v.v.)

## 🛠️ Hướng Dẫn Build (Dành cho Developer)

Dự án sử dụng Theos để biên dịch.
```bash
# Clone dự án
git clone https://github.com/romlayvn/ShimaStyle.git
cd ShimaStyle

# Biên dịch ra file .deb
make package FINALPACKAGE=1
```
